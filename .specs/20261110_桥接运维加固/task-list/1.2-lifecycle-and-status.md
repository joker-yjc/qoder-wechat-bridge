# 1.2 冲突文案与运行实例展示

- 所属任务组：T1. 实例互斥
- 硬前置：1.1

## 目标

提供"已在运行"的中文文案生成，并让 `qoder-wechat status` 显示当前实例 pid 与存活状态。本任务不改启动流程，只做可观测性与文案。

## 实现要点

- `lifecycle.describeOwner(owner, launchdLabel)`：输出 pid、状态目录、**启动时间、工作目录**、launchd label（若有）与可直接执行的停止命令；字段缺失时输出 `(未知)`；非 launchd 给 `qoder-wechat stop && qoder-wechat run`，launchd 提示先执行 `qoder-wechat stop` 获取 bootout 命令。
- `status.ts`：`StatusContext` 增加 `runInfo` / `runAlive`；`buildStatusLines` 在会话信息附近新增 `运行实例：pid N（存活）` 或 `运行实例：未运行`。
- `cli.ts` 的 `status` 分支读取 `readRunInfo()` 与 `isAlive()`，填充上下文；不影响其它命令。
- 单测覆盖 launchd / 非 launchd 两种文案、启动时间与工作目录（含缺失）、status 有新实例 / 无实例两种情况。

## 验收标准

- 触达文件 Lines 覆盖率 ≥ 95%；
- 无实例时输出"未运行"，有实例时含 pid；
- launchd 文案含 label，普通文案含可直接复制执行的停止命令；
- 拒绝文案含 pid、启动时间、工作目录（需求 1.2、5.1）。
