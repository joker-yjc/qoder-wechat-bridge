# 2.1 会话类型与清单解析

- 所属任务组：T2. 会话清单模块 sessions.ts
- 硬前置：—

## 目标

新建 `src/bridge/sessions.ts`，定义 `SessionEntry`/`SessionError` 与纯函数 `parseSessionList`，固定 R2 文本解析契约（行尾 UUID 锚定）。

## 实现要点

- 先写失败单测：正常多行、名称含空格/括号/中文、空清单、表头跳过、坏行忽略、全坏抛 `SessionError('parse')`、行尾 UUID 锚定切分。
- `SessionEntry { index, name, lastActive, sessionId }`；`SessionError extends Error { kind: 'not_installed'|'not_logged_in'|'timeout'|'parse'|'spawn'|'rename' }`。
- `parseSessionList(stdout)` 正则 `/^\s*(\d+)\.\s*(.*?)\s*\(([^)]*)\)\s*\[([0-9a-fA-F-]{36})\]\s*$/`；名称非贪婪允许括号/中文；跳过 `Available sessions...` 表头与空行；无法匹配的行忽略；全部无法匹配抛 `SessionError('parse')`。
- 纯函数无 IO，便于 100% 覆盖。
