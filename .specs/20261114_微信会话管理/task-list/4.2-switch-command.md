# 4.2 /switch 处理器

- 所属任务组：T4. 会话命令处理器
- 硬前置：1.1, 2.2

## 目标

新增 `/switch <目标>` 变更命令处理器：解析序号/id/名称，改活动会话指针，不触碰会话内容。

## 实现要点

- 先写失败单测：序号用 catalogs 缓存命中；无缓存 → "请先发 /sessions"；id/名称用新鲜 listSessions 校验；越界/不唯一/未找到 → 中文错误不改指针；目标即当前 → "已在该会话"；无参 → 用法 + 当前会话；成功改 sessionId/updatedAt 并 persistState。
- 新建 `src/bridge/commands/switch.ts`，导出 `CommandHandler`（def `/switch <序号|id|名称>`，`requiresIdle: true`）。
- `handle`：序号 → `ctx.catalogs.get(userId)`；id/名称 → `ctx.deps.listSessions` 取新鲜清单；`resolveSession` 命中 → 改 `state.sessions[userId]` → `ctx.persistState()` → 回显（含名称与截断 id）。
- 在 `COMMAND_HANDLERS` 登记。
