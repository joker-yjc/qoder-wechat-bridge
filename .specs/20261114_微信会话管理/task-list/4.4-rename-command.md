# 4.4 /rename 处理器

- 所属任务组：T4. 会话命令处理器
- 硬前置：1.1, 2.3

## 目标

新增 `/rename <名称>` 变更命令处理器：给当前活动会话改名（R1 受支持路径），无会话/非法名称给可读提示。主人已确认本期保留交付（P1）。

## 实现要点

- 先写失败单测：无活动会话 → "当前没有会话…"；名称空 → 用法；名称超 60 → 拒绝；renameSession 成功 → 回显新名；失败 → 中文错误不假装成功。
- 新建 `src/bridge/commands/rename.ts`，导出 `CommandHandler`（def `/rename <名称>`，`requiresIdle: true`）。
- `handle`：取 `state.sessions[userId]`，无 → 提示；名称校验（非空、≤60）；`ctx.deps.renameSession({ bin, cwd, sessionId, name, timeoutMs: qoderTimeoutMs, permissionMode })` → 成功回显 / 失败中文。
- 在 `COMMAND_HANDLERS` 登记。
