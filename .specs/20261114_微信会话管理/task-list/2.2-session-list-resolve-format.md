# 2.2 列表 / 目标解析 / 渲染

- 所属任务组：T2. 会话清单模块 sessions.ts
- 硬前置：2.1

## 目标

在 `sessions.ts` 补 `listSessions`（execFileSync 调 `--list-sessions`）、`resolveSession`（序号/id/名称）、`formatSessionList`（标活动会话/截断/空清单）。

## 实现要点

- 先写失败单测：listSessions mock execFileSync 成功/未安装/超时/cwd 透传；resolveSession 序号命中/越界、完整 id、唯一短 id、不唯一短 id、名称精确/大小写、未找到；formatSessionList 标 `← 当前`、截断到 limit、空清单友好提示、id 截断 8 位。
- `listSessions(bin, cwd)`：`execFileSync(bin, ['--list-sessions'], { env: cleanEnv(), cwd, encoding:'utf-8', timeout: 20000, stdio:['ignore','pipe','ignore'] })` → `parseSessionList`；按错误分类抛 `SessionError`（not_installed/not_logged_in/timeout）。
- `resolveSession(input, catalog)`：纯数字→序号；UUID 或唯一短 id 前缀→命中（多条→不唯一）；名称大小写不敏感精确→命中；否则 `{ok:false, reason}`。
- `formatSessionList(catalog, activeId, limit)`：空→"当前工作目录下还没有会话…"；超 limit 只列最近 N 条 + "仅显示最近 N 条"；活动行尾 `← 当前`。
