# 3.1 runQoder name 入参

- 所属任务组：T3. 创建命名与配置
- 硬前置：—

## 目标

`QoderRunInput` 新增可选 `name`，`runQoder` 在创建会话时经 `-n` 应用显示名，供 `/new <名称>` 后的首次创建使用。

## 实现要点

- 先写失败单测：传 `name` → args 含 `-n <name>`；不传 → 不含 `-n`；`name` 与 `sessionId`（`-r`）共存时两者都在；空白 name 不追加。
- `src/bridge/qoder.ts:13` `QoderRunInput` 加 `name?: string`（JSDoc：创建会话时的显示名）。
- `runQoder`（qoder.ts:184）args 构建：在 `sessionId` 分支（qoder.ts:194）之后加 `if (input.name?.trim()) args.push('-n', input.name.trim())`。
- 仅调用方在无 sessionId 时传 name（5.1 接线），普通续接不传，避免误改名。
