# 4.1 /sessions 处理器

- 所属任务组：T4. 会话命令处理器
- 硬前置：1.1, 2.2, 3.2

## 目标

新增 `/sessions` 只读命令处理器：列当前工作目录会话、标活动会话、截断到 limit、刷新内存缓存，不改指针。

## 实现要点

- 先写失败单测：正常清单标 `← 当前`；空清单友好提示；超 limit 截断；listSessions 失败 → 中文错误；执行后指针不变；catalogs 被刷新。
- 新建 `src/bridge/commands/sessions.ts`，导出 `CommandHandler`（def `/sessions`，`requiresIdle: false`）。
- `handle`：`ctx.deps.listSessions(config.qoderBin, ctx.workdir())` → `formatSessionList(catalog, activeId, config.sessionListLimit)` → `ctx.catalogs.set(userId, catalog)` → `ctx.reply`；catch → `log.warn` + 中文错误。
- 在 `COMMAND_HANDLERS` 登记。
