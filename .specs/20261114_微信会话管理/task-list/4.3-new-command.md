# 4.3 /new 处理器

- 所属任务组：T4. 会话命令处理器
- 硬前置：1.1

## 目标

新增 `/new [名称]` 变更命令处理器：清活动会话指针、可选记待用显示名，不立即调 CLI、不耗额度。创建时消费待用名在 5.1 接线。

## 实现要点

- 先写失败单测：无参清指针 + 清 pendingNames；带名称（≤60）记 pendingNames；名称超长拒绝；执行不调用 qodercli（deps 未被调用）；回显含名称；旧会话内容不删。
- 新建 `src/bridge/commands/new.ts`，导出 `CommandHandler`（def `/new [名称]`，`requiresIdle: true`）。
- `handle`：`delete state.sessions[userId]`；名称非空且 ≤60 → `ctx.pendingNames.set(userId, name)`，否则 `ctx.pendingNames.delete(userId)`；`ctx.persistState()`；回显。
- 在 `COMMAND_HANDLERS` 登记。
