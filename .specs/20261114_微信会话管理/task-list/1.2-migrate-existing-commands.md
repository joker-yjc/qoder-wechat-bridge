# 1.2 既有四命令迁入处理器

- 所属任务组：T1. 命令注册表骨架与既有命令迁移
- 硬前置：1.1

## 目标

把既有 `/help` `/reset` `/status` `/model` 逻辑原样迁入独立处理器模块并登记到注册表，行为完全不变（N1）。service 的 if 链在 5.1 一次性替换为 `dispatchCommand`，本任务不接 service。

## 实现要点

- 先写回归失败单测：四命令经 `dispatchCommand` 的回复与既有 if 链一致（/help 文本、/reset 清指针、/status 行、/model 列表/切换/default）。
- 新建 `src/bridge/commands/help.ts`、`reset.ts`、`status.ts`、`model.ts`，各导出一个 `CommandHandler`；逻辑从 service.ts:501–563 原样搬移，回复改经 `ctx.reply`。
- `/model` 保留 `deps.listModels` 注入与 `resolveModel`/`formatModelList` 调用；`requiresIdle` 均不设（既有行为不变）。
- 在 `COMMAND_HANDLERS` 登记四处理器；`COMMANDS` 自动含四命令。
- 处理器内异常捕获 → `ctx.reply` 中文错误，不抛出。
