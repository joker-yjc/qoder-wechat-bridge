# 2.3 headless 重命名

- 所属任务组：T2. 会话清单模块 sessions.ts
- 硬前置：2.1

## 目标

在 `sessions.ts` 补 `renameSession`，走 R1 实测成立的受支持路径 `-r <id> -n <新名> -p`，异步 spawn 不阻塞事件循环。

## 实现要点

- 先写失败单测：mock cross-spawn 成功（is_error=false）/is_error=true/超时/spawn 错误；断言 args 含 `-r <id> -n <name> -p`、`-w cwd`、`--permission-mode`；cleanEnv 剥离 QODER_*。
- `renameSession({ bin, cwd, sessionId, name, timeoutMs, permissionMode })`：cross-spawn 起 `qodercli -p -o json --permission-mode <mode> -w <cwd> -r <id> -n <name> '重命名'`，`cleanEnv()`，超时 `timeoutMs`，输出上限复用 `MAX_OUTPUT_BYTES` 口径。
- 解析 result：`is_error=false` → `{ok:true}`；否则 `{ok:false, error}`（中文归类，不直达 stderr）。
- 代价登记：跑一个完整模型轮次（约 0.05 积分 + 一条 junk 轮次），见设计 §9；不逆向写 jsonl。
