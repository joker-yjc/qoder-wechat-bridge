# 2.1 SessionRecord.bin + activeSession + 单测

- 所属任务组：T2. 会话指针 bin 标签
- 硬前置：1.1

## 目标

给会话指针加后端标签并提供读取过滤 helper：`SessionRecord` 新增可选 `bin` 字段；`activeSession(state, userId, bin)` 按后端 **kind** 比较（D1，主人已批准），跨后端返回 undefined，存量缺 bin 视为 `DEFAULT_CONFIG.qoderBin`（国际版）。`normalizeState` 不动，存量 state.json 零迁移。

## 实现要点

- `src/config.ts` `SessionRecord` 加 `bin?: string`（JSDoc：创建/续接时的后端 bin；存量缺失视为默认）。
- 新增导出 `activeSession(state: State, userId: string, bin: string): SessionRecord | undefined`：无记录 → undefined；`recordBin = record.bin ?? DEFAULT_CONFIG.qoderBin`；`backendProfile(recordBin).kind === backendProfile(bin).kind` → 返回记录，否则 undefined。
- import `backendProfile` from `./bridge/backend.js`（config.ts 已有 import bridge/error-class 先例，backend.ts 零依赖无循环）。
- `normalizeState` / `DEFAULT_CONFIG` / `ENV_OVERRIDES` 一律不动（D5：读时兜底，下次成功任务自然补写 bin）。
- 先写失败用例（`test/unit/config.test.ts` 追加）：bin 一致返回记录；跨 kind 返回 undefined；存量缺 bin + 当前 qodercli 返回记录；存量缺 bin + 当前 CN 返回 undefined；同 kind 不同写法（`qodercli` ↔ `/usr/local/bin/qodercli`、`qoderclicn` ↔ `qodercn`）返回记录；normalizeState 透传含 bin / 缺 bin 的 sessions 不报错。
