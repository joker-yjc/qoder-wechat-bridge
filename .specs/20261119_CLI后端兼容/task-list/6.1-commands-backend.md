# 6.1 四命令处理器适配 + 单测

- 所属任务组：T6. 命令处理器适配
- 硬前置：2.1

## 目标

status / sessions / switch / rename 四个处理器接入 `activeSession` 与 bin 写入：/status 增"后端"行且跨后端显示尚未创建；/sessions 跨后端不标"← 当前"；/switch 写指针带 bin、turns 不串后端；/rename 跨后端走"当前没有会话"提示。new/reset/delete/model/help 不动（设计 §4.3 已论证安全）。

## 实现要点

- `src/bridge/commands/status.ts`：`const record = activeSession(ctx.state, ctx.userId, ctx.config.qoderBin)`；lines 在"工作目录"行后插 `后端：${ctx.config.qoderBin}`。
- `src/bridge/commands/sessions.ts`：`const activeId = activeSession(ctx.state, ctx.userId, ctx.config.qoderBin)?.sessionId`。
- `src/bridge/commands/switch.ts`：current 改 `activeSession`；写指针（44 起）加 `bin: ctx.config.qoderBin`。
- `src/bridge/commands/rename.ts`：current 改 `activeSession`（跨后端 → 既有"当前没有会话，先发消息创建后再 /rename"路径）。
- 先写失败用例（照 makeCtx + dispatchCommand 范式）：`test/unit/commands.test.ts` 追加 /status 含"后端：qoderclicn"行、跨后端指针显示"（尚未创建）"与轮次 0；`test/unit/commands-session.test.ts` 追加 /switch 写 bin 与跨后端 turns=0、/rename 跨后端提示、/sessions 跨后端不标当前。
