# 7.1 failure/sessions 文案中性化 + 断言同步

- 所属任务组：T7. 文案中性化
- 硬前置：—

## 目标

用户可见错误文案中写死的 `qodercli` 统一改为"Qoder CLI"（D7：不内插 bin 名），错误归类、errorCode、截断长度、去重窗口口径全部不变；日志与诊断保留命令原文。与主线解耦，无硬前置。

## 实现要点

- `src/bridge/failure.ts`：89/99/100/104/107/110/116 行用户模板 `qodercli` → `Qoder CLI`（对照设计 §3.2 表逐条）。
- `src/bridge/sessions.ts`：96（请升级 Qoder CLI）/127（未安装提示）/250/314（无法启动 Qoder CLI）用户可见文案替换；技术注释可同步。
- `error-class.ts` 归类逻辑、`buildUserErrorReply` 截断/去重、`SessionError` 枚举一律不动。
- 同步既有断言：`test/unit/failure.test.ts`、`test/unit/sessions.test.ts` 中匹配旧文案的期望值改为新文案；归类/截断/去重相关断言不动。先改用例（红）再改文案（绿）。
