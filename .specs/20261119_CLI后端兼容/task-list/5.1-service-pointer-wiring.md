# 5.1 service 指针过滤/写 bin/日志 + 单测

- 所属任务组：T5. 服务层接线
- 硬前置：2.1、3.1

## 目标

`processTask` 用 `activeSession` 过滤跨后端指针：跨后端首条消息直接新建（不带 -r）、turns 从 1 起、写指针带 bin、log.info 记录切换；同后端续接与降级重试语义不变。启动日志记录后端 bin 与画像。

## 实现要点

- `src/bridge/service.ts` processTask（551 起）：`const rawRecord = state.sessions[userId]; const record = activeSession(state, userId, config.qoderBin);`；`if (rawRecord && !record)` → `log.info('后端已切换，旧会话指针不可续接，将新建会话', { userId, taskId, oldBin: rawRecord.bin ?? DEFAULT_CONFIG.qoderBin, newBin: config.qoderBin })`。
- 指针写入（633 起）加 `bin: config.qoderBin`；turns 表达式 `(record?.turns ?? 0) + 1` 不动（record 已过滤，跨后端自动从 1 起）。
- 降级重试（605）、pendingNames 消费、runQoder 其余入参不动。
- 启动日志（1205 '桥接服务启动'）加字段：`qoderBin: config.qoderBin, backend: backendProfile(config.qoderBin).kind, memoryEnv: backendProfile(config.qoderBin).memoryEnv`。
- 先写失败用例：`test/unit/service.test.ts` 追加——跨后端首条消息（runQoder 入参无 sessionId、成功后指针 bin=新值 turns=1、切换日志触发）；同后端续接不变（带 -r、turns 累加）；存量缺 bin 指针在 qodercli 下正常续接、在 CN 下新建。`test/unit/service-startup.test.ts` 断言启动日志含 backend/memoryEnv 字段。
