## 目标

新增 `src/bridge/backend.ts`：由 `qoderBin` 命令名推导后端画像（kind / memoryEnv / configDirName）的纯函数。CN 判定精确匹配官方包两个 bin 名 `qoderclicn` / `qodercn`，其余回落国际版。零运行时探测、零副作用、仅依赖 `node:path`。TDD：先写失败用例再实现。

## 实现要点

- 导出 `BackendProfile` 接口：`kind: 'intl' | 'cn'`、`memoryEnv: string`、`configDirName: string`（JSDoc 中文注释，照仓内规范）。
- `CN_BINS = new Set(['qoderclicn', 'qodercn'])`（来源：`@qodercn-ai/qoderclicn` package.json bin 字段实测）。
- `backendProfile(bin)`：`path.basename(bin)` → 去 `.cmd/.exe/.bat/.ps1` 扩展名（大小写不敏感）→ `toLowerCase()` → 命中 CN_BINS 返回 CN 画像 `{kind:'cn', memoryEnv:'QODERCN_MEMORY_HEADLESS', configDirName:'.qoder-cn'}`，否则国际版 `{kind:'intl', memoryEnv:'QODER_MEMORY_HEADLESS', configDirName:'.qoder'}`。
- 画像值来源注释：CN 包 `yo()` 前缀函数 `Gu="QODERCN_"` 与品牌常量 `BRAND_USER_CONFIG_DIR_NAME=".qoder-cn"`（2026-11-19 取证）。
- 先写 `test/unit/backend.test.ts` 失败用例：三个官方名、posix 绝对路径、四种脚本扩展名、大小写混合、未知名字回落、空串回落。
