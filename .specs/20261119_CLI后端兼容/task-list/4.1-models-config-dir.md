# 4.1 models.ts 配置目录按后端 + 单测

- 所属任务组：T4. 模型目录按后端
- 硬前置：1.1

## 目标

`/model` 自定义模型按后端读对应配置目录：CN → `~/.qoder-cn/settings.json`，国际版 → `~/.qoder/settings.json`；`QODER_CONFIG_DIR` 覆盖优先（两版通用）。内置模型仍走当前 bin `--list-models`；缓存按 bin 隔离（既有 `cache.bin` 键已满足，不改）；settings 缺失/损坏降级空列表（既有行为）。

## 实现要点

- `src/models.ts` `qoderConfigDir(bin: string)`：`process.env.QODER_CONFIG_DIR ?? path.join(os.homedir(), backendProfile(bin).configDirName)`。
- `listCustomModels(bin)` 透传 bin 给 qoderConfigDir；`listModels(bin)` 调 `listCustomModels(bin)`；解析结构（providers.<id>.models[]）与 catch 降级不动。
- `listBuiltinModels(bin)` 不动。
- 新增 `test/unit/models.test.ts`（先写失败用例）：临时目录写 settings.json + `QODER_CONFIG_DIR` 注入断言覆盖优先；CN bin 默认目录名推导（mock os.homedir 或 env 注入）；settings 损坏 → 自定义空列表不报错；缓存按 bin 隔离（切换 bin 不命中旧缓存）；内置模型走当前 bin（mock execFileSync）。
- 测试隔离：用 `QWB_STATE_DIR`/临时目录与 env 还原，避免污染生产配置（对齐 v2-backlog 测试卫生登记）。
