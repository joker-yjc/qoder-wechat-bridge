# 2.2 去重窗口配置项与 lastFailure 状态归一化

- 所属任务组：T2. 文案与配置
- 硬前置：1.1

## 目标

新增本期唯一的配置项 `errorDedupWindowMs`，并给 `State` 增加可空的 `lastFailure` 字段供 `status` 读取。

**关键设计决策 1：`version` 保持 2，不做迁移脚本。** 新增字段可空且 `normalizeState` 已做字段级兜底，旧状态文件读取即为 `null`，天然兼容。

**关键设计决策 2：错误提示字符上限不新增配置项。** 一期已有 `userErrorMaxChars` / `QWB_USER_ERROR_CHARS`（默认 300），本期直接复用（N3）。

**边界条件**：`state.json` 可能被用户手改，`normalizeState` 必须对非法值降级而不是让 `status` 抛异常。

## 实现要点

- 修改 `src/config.ts`：
  - `import type { QoderErrorClass } from './bridge/error-class.js'` —— 单向依赖，`error-class.ts` 不引用 `config.ts`，**无循环依赖**。
  - 新增导出类型：
    ```ts
    export interface LastFailureRecord {
      kind: string;                      // 传输层类别，取自 QoderErrorKind
      errorClass: QoderErrorClass;       // 业务语义类别
      errorCode?: string;                // 归一化后的 error_code
      exitCode: number | null;           // null 表示未知（超时 / spawn 失败）
      at: number;                        // 毫秒时间戳
      taskId: string;
    }
    ```
  - `Config` 新增 `errorDedupWindowMs: number`；`DEFAULT_CONFIG` 为 `10 * 60_000`。
  - `ENV_OVERRIDES` 追加 `['errorDedupWindowMs', 'QWB_ERROR_DEDUP_WINDOW_MS', (v) => Number(v)]`，与既有数值型配置写法一致。
  - `State` 新增 `lastFailure: LastFailureRecord | null`；`DEFAULT_STATE` 为 `null`。
  - `normalizeState` 追加字段级归一化（`isRecord(raw.lastFailure)` 为假时直接 `null`）：
    - `kind`：非 string → `'exit'`
    - `errorClass`：非法值 → `'unknown'`（用本文件内私有守卫 `isErrorClass` 检查是否属四个合法值）
    - `errorCode`：非 string → `undefined`
    - `exitCode`：非 number → `null`
    - `at`：走既有 `asNumber(raw.at, 0)`
    - `taskId`：非 string → `''`
  - `isErrorClass` 为本文件私有函数，**不导出**——它的唯一作用是防止手改 state.json 后 `ERROR_CLASS_LABEL[...]` 取到 `undefined`。
- 每个新增字段与函数补 JSDoc（全局规范）。
- 单测委托 `unit-test` skill，覆盖设计 8.2 的 `config.ts` 行。

## 验收标准

- `src/config.ts` Lines 覆盖率 ≥ 95%。
- `DEFAULT_CONFIG.errorDedupWindowMs === 600000`；设 `QWB_ERROR_DEDUP_WINDOW_MS=60000` 后 `loadConfig()` 读到 `60000`。
- `DEFAULT_STATE.lastFailure === null`；`normalizeState({})` 返回 `lastFailure: null`。
- 脏数据降级：`errorClass: 'quota'`（非法值）→ `'unknown'`；`at: 'abc'` → `0`；`taskId` 缺失 → `''`；`exitCode` 缺失 → `null`；`lastFailure: 'x'`（非对象）→ `null`。
- `normalizeState` 输出的 `version` 仍为 `2`。
- 一期既有用例（`attempts` 迁移、损坏状态回退、其它 `QWB_*` 覆盖）全部保持绿。
