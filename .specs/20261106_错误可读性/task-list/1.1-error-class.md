# 1.1 语义字段归一化与四类分类纯模块

- 所属任务组：T1. 语义分类与去重（纯逻辑）
- 硬前置：—

## 目标

新增一个零依赖纯模块，把 qodercli `result` 行里的语义字段归一化并映射到 `model_quota` / `output_limit` / `auth` / `unknown` 四类之一。这是本期所有下游模块的类型与决策来源，必须最先落地。

**关键设计决策**：入参全部声明为 `unknown`，归一化集中在本模块内完成——`result` 行来自外部进程，已实测到 `error_code` 同时存在 number（`110`）与 string（`"max_output_tokens"`）两种形态，下游不应再判类型。

**边界条件**：分类特征**只认三条硬规则**（均有实测或上游枚举支撑），其余一律 `unknown`。上游枚举里的 `billing_error` / `rate_limit` / `invalid_request` / `server_error` 零实测样本，本期**不**归入任何已知类别（设计评审已确认）。

## 实现要点

- 新增 `src/bridge/error-class.ts`，导出：
  - `type QoderErrorClass = 'model_quota' | 'output_limit' | 'auth' | 'unknown'`
  - `const ERROR_CLASS_LABEL: Record<QoderErrorClass, string>` —— `模型额度已用尽` / `回答被截断` / `凭据已失效` / `未归类`
  - `interface QoderSemanticFields`（`errorCode` / `errorMessage` / `errors` / `stopReason` 为 `unknown`，`isError?: boolean`，`result?: string`）
  - `interface QoderErrorClassification`（`errorClass`、`errorCode?: string`、`detail?: string`）
  - `function classifyQoderError(fields: QoderSemanticFields): QoderErrorClassification`
- **归一化规则**（按设计 5.1.1）：
  - `errorCode`：有限 number → `String(n)`；非空 string → trim 值；`null` / `undefined` / 对象 / `NaN` → `undefined`。数字 `110` 与字符串 `"110"` 归一后同为 `"110"`，规则只需比较一次。
  - `errors`：`Array.isArray` 时取第一个非空 string 元素，否则忽略。
  - `errorMessage` / `stopReason`：仅 `typeof === 'string'` 时采用。
  - `detail`：按 `errors[0]` → `errorMessage` → `result` 顺序取首个非空字符串，**原样返回**（不截断、不脱敏；脱敏在落盘与日志处做）。
- **分类规则**（短路，优先级固定）：
  1. `errorCode === '110'` 或 `errorMessage` 含 `Billing daily count exceeded` → `model_quota`
  2. `errorCode === 'max_output_tokens'`，或 `stopReason === 'max_tokens'` 且 `isError === true` → `output_limit`
  3. `errorCode === 'authentication_failed'` → `auth`
  4. 其它 → `unknown`
- 优先级理由：`error_code` 是单值字段，三条规则实测不会同时命中；固定优先级让 `error_code=110` + `stop_reason=max_tokens` 这类理论组合有确定结果（额度是因、截断是果，判 `model_quota`）。
- `errorMessage` 的包含匹配需大小写不敏感？——**不需要**，实测样本为精确的 `Billing daily count exceeded`；用 `includes` 原样匹配，避免过度宽松导致误判。
- 遵循全局 JSDoc 规范：模块头 `@module bridge/error-class`，每个导出函数写 `@param` / `@returns`。
- 单测委托 `unit-test` skill 编写，覆盖设计 8.2 的 `bridge/error-class.ts` 行：三条硬规则各自命中、number/string `110` 等价、优先级组合、`errorCode` 为 `null` / 对象 / `NaN` / 未收录字符串（如 `"rate_limit"`）→ `unknown`、`errors` 非数组 / 元素非字符串 / 空数组、`detail` 三级回退顺序、空输入 → `unknown`。
