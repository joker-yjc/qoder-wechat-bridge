# 2.1 语义模板短路、ack 文案与一期文案回归

- 所属任务组：T2. 文案与配置
- 硬前置：1.1

## 目标

让 `buildUserErrorReply` 在已知语义类别下改用固定中文模板，并新增 ack 文案函数。**从代码层面保证英文原文不会作为回复正文下发**（需求 1.5）。

**关键设计决策**：语义分支**不使用 `input.detail`**——不是"约定不用"，而是分支内根本不引用该变量，让需求 1.5 成为结构性保证而非纪律要求。`detail` 仍只被 `spawn` 分支使用（取 ENOENT 等首行原因），该行为一期已验收，保留。

**硬门禁**：六个传输层模板（`timeout` / `spawn` / `empty` / `parse` / `exit` / `is_error`）在 `errorClass` 为 `'unknown'` 或 `undefined` 时必须**逐字不变**，否则破坏 N1 与一期正确性属性 16。

## 实现要点

- 修改 `src/bridge/failure.ts`：
  - `buildUserErrorReply` 入参新增可选 `errorClass?: QoderErrorClass`（从 `./error-class.js` 导入类型），签名向后兼容。
  - 在现有 `switch (input.kind)` **之前**插入语义短路 `switch (input.errorClass)`，三个已知类别各返回一条模板并经 `fit(text, input.maxChars)` 限长；`'unknown'` 与 `undefined` 落到下方既有 switch。
  - 复用现有的 `code` 计算（`exitCode` 为 `undefined` / `null` → `'未知'`），模板末尾保留 `（退出码 {code}）`。
- **三条模板文案（逐字，含标点）**：
  - `model_quota`：`模型额度已用尽：今日调用次数达到上限。可稍后重试，或发 /model 切换模型。（退出码 {code}）`（47 字符）
  - `output_limit`：`回答被截断：模型输出达到上限，本次没有完整结果。可发 /model 换输出上限更大的模型，或把任务拆小。（退出码 {code}）`（59 字符）
  - `auth`：`Qoder 凭据已失效：需在本机重新登录 qodercli 后重试。（退出码 {code}）`（41 字符）
- 文案约束（设计 3.1）：
  - 建议动作必须是用户在微信里**真能执行**的，`/model` 是既有命令，故 `model_quota` / `output_limit` 直接引用它。
  - `auth` **不能**写成"点击重新登录"——qodercli 凭据只能在本机刷新，微信侧无入口，文案明说"需在本机"。
  - 不写死具体模型名（需求 2.2），避免模型列表变化后文案过期。
  - 三条模板均远小于 300，但仍统一走 `fit()`，保证 `maxChars` 被调小时行为一致。
- 新增 ack：
  - `export const ACK_MAX_CHARS = 60`（模块常量，**不做成配置项**——需求 3.3 只要求"不超过 60"，实测最长 34 字符）
  - `export function buildAckText(input: { errorClass: QoderErrorClass; firstAt: number; suppressed: number }): string`
  - 实现：`` `（${ERROR_CLASS_LABEL[errorClass]}同 ${hhmm} 那条，本次为第 ${suppressed} 次，已略）` ``
  - `hhmm` 用 `new Date(firstAt).toTimeString().slice(0, 5)`，**不用** `toLocaleTimeString`——后者输出含秒且受 ICU locale 影响，前者格式固定为 `HH:MM:SS GMT+xxxx`，切片结果稳定。
  - **不做运行时截断**：长度上界 = `（`1 + label≤7 + `同 `2 + hhmm 5 + ` 那条，本次为第 `9 + suppressed≤4 + ` 次，已略）`6 = 34 字符，恒小于 60。改由单测穷举断言。
- `ERROR_CLASS_LABEL` 从 `./error-class.js` 导入，**不在本文件重复定义**，避免 label 与 status 输出漂移。
- 单测委托 `unit-test` skill，覆盖设计 8.2 的 `bridge/failure.ts` 行。

## 验收标准

- `src/bridge/failure.ts` Lines 覆盖率 ≥ 95%。
- 三个语义模板各有关键短语断言（`模型额度已用尽` / `回答被截断` / `凭据已失效`）。
- **原文不下行**：传入 `detail: "The model reached its output token limit…"` 且 `errorClass: 'output_limit'` 时，返回文本**不含**该英文片段。
- **一期回归**：`errorClass` 为 `'unknown'` 与 `undefined` 两种情况下，六个传输层 kind 的文案与改造前逐字相同（含 `。详见本机日志。` 后缀与 `退出码 未知` 分支）。
- `maxChars` 限长生效，且截断后保留"…详见本机日志。"收尾（沿用一期 `fit()` 规则）。
- `buildAckText` 对四个 label × `suppressed ∈ {1, 99, 9999}` 共 12 种组合断言长度 ≤ 60；`hhmm` 切片格式为 `HH:MM`。
