# 4.3 service 启动流程：清理、预检告警与 Node 指纹

- 所属任务组：T4. 服务编排与命令
- 硬前置：3.2、4.2

## 目标

把启动预检、诊断清理、outbox 清理和 Node 指纹检测接入 `runService` 启动流程；预检失败只告警，不阻止服务运行。

## 实现要点

- `runService` 启动顺序：
  1. `ensureDirs()`；
  2. `pruneDiagnostics(diagnosticRetentionDays)`；
  3. `loadConfig / loadState / normalizeState`；
  4. `pruneOutbox()`；
  5. `runPreflight()`；
  6. 未登录则 `login()`；
  7. `writeRunInfo()`；
  8. `notifyClient(start)`；
  9. `runLoop()`。
- 预检失败：
  - 写结构化 error 日志（含 `failureKind / nodeVersion / nodePath / qoderPath / durationMs`）；
  - 若 `state.contextTokens[ownerUserId]` 存在，最多发送一条短告警（单条、≤300 字）；
  - 发送失败只记 warn，不重试、不入 outbox；
  - 不阻止任务处理，不引入降级态。
- 启动时保存 `nodeFingerprint()`；每条任务执行前重新检测一次，路径 / inode / 版本变化时写 warn 并更新快照，不自动重启。
- 启动日志记录 Node 路径 / 版本、qodercli 路径 / 版本。
- `runPreflight` 通过 `RuntimeDeps` 注入，便于测试。
