# 3.2 启动本地预检与 Node 指纹变化检测

- 所属任务组：T3. qodercli 与运维
- 硬前置：1.2

## 目标

实现设计 5.1.7 的本地预检：启动时检查 Node 版本、qodercli 可执行与版本，记录路径/版本；运行期检测 Node 二进制变化并告警。不做最小 `-p` 探针，不引入降级态。

## 实现要点

- 新增 `src/bridge/preflight.ts`，导出：
  - `PreflightResult`（`ok / node / qodercli / failures`）
  - `runPreflight({ qoderBin, versionTimeoutMs, deps? })`
  - `nodeFingerprint()`
  - `detectNodeChange(prev, next)`
- 检查项：
  1. Node 主版本 ≥ 20，记录 `version / execPath / ino / mtimeMs`；
  2. qodercli 解析：绝对路径 `X_OK`，否则 `which`（Windows `where`）；
  3. `qodercli --version`，超时 `preflightVersionTimeoutMs`；
  4. 记录 qodercli 路径与版本。
- 失败类别：`node_version` / `qoder_missing` / `qoder_version`。
- 预检失败只返回结构化结果，不发消息、不写 outbox；由 service 在 4.3 决定记日志和发短告警。
- `detectNodeChange` 比较路径、inode、mtime、版本，返回变化原因或 `null`。
- 依赖注入 `deps`（`nodeVersion / statFile / resolveBin / runVersion / platform`）便于单测；默认实现使用 `node:fs` / `node:child_process`。
