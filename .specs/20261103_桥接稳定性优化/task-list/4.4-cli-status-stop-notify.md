# 4.4 status 字段、stop 输出与 notify 队列治理

- 所属任务组：T4. 服务编排与命令
- 硬前置：1.2、2.1、3.3

## 目标

把新增的队列 / 隔离 / 额度信息暴露到 `status`，把 `stop` 的手动提示与退出码接到 CLI，并让 `notify` 的待发提醒受 TTL 与 outbox 上限约束。

## 实现要点

- 新增 `src/status.ts`：纯函数 `buildStatusLines(config, state, context)`，输出：
  - outbox 总数、最旧消息年龄、总字节；
  - 隔离区数量；
  - 额度连续告警（`state.quota.streak / lastAt`）；
  - 保留现有配置 / 会话 / 附件字段。
- `src/cli.ts`：
  - `printStatus()` 改用 `buildStatusLines`；
  - `stop` 改用 `lifecycle.formatStopOutcome`，按 `idle / stopped / timeout / supervised / conflict / EPERM` 输出并返回对应退出码；
  - `--help` 补充 outbox / 诊断相关 `QWB_*` 说明。
- `src/notify.ts`：
  - `takePending` 消费时丢弃 `now - createdAt > outboxTtlMs` 的提醒并写日志；
  - 入队统一走 `pushOutbox`，受 `outboxMaxItems` 约束；
  - 分片继续使用现有 `chunkText(text, maxReplyChars)`。
- `src/index.ts` 导出 `buildStatusLines`。

## 验收标准

- `src/status.ts`、`src/notify.ts` Lines 覆盖率 ≥ 95%。
- 用例覆盖：空队列显示 0、最旧年龄、隔离区数量、额度告警、notify 过期丢弃、notify 超限丢最旧。
- `stop` 输出包含设计 5.1.8 的 bootout / 验证 / 恢复 / 兜底命令。
- `status` 不输出 token、完整消息正文。
