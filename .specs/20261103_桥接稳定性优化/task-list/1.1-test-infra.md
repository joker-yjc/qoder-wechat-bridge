# 1.1 搭建 vitest / coverage / fast-check 测试基础设施

- 所属任务组：T1. 测试与模型基础
- 硬前置：—

## 目标

为后续所有子任务提供统一的测试与覆盖率基础设施，不修改任何业务源码。

## 实现要点

- 安装开发依赖：`vitest`、`@vitest/coverage-v8`、`fast-check`，版本需兼容 Node ≥ 20。
- `package.json` 增加脚本：`test`（`vitest run`）、`test:watch`（`vitest`）、`test:coverage`（`vitest run --coverage`）。
- 新增 `vitest.config.ts`：Node 环境、包含 `test/**/*.test.ts`、排除 `dist` / `node_modules`、覆盖率 provider 为 v8、输出 text + json-summary。
- 覆盖率阈值先不配置，留到 5.2 统一开启，避免中间任务因覆盖率未达标阻塞。
- 新增 `test/unit/smoke.test.ts`，用现有 `chunkText` 做一条最小回归（`chunkText('abc', 10)` 返回 `['abc']`），确认 TS + ESM + vitest 链路可用。
- 创建 `test/unit/`、`test/integration/`、`test/fixtures/`、`test/helpers/` 目录。

## 引用

## 验证命令

```bash
npm test
npm run test:coverage
```

## 验收标准

- `npm test` 通过，至少 1 个 smoke 用例。
- `npm run test:coverage` 能生成覆盖率报告。
- 不修改 `src/` 下任何源码。
