# 2.3 诊断落盘、脱敏与过期清理

- 所属任务组：T2. 纯逻辑核心
- 硬前置：1.1

## 目标

实现设计 5.1.5 的诊断模块：把 qodercli 失败的完整输出写入仅当前用户可读的独立文件，单文件 ≤64KB，并脱敏敏感信息。

## 实现要点

- 新增 `src/diagnostics.ts`，导出：
  - `writeDiagnostic(input, opts?)`：`input` 含 `taskId / sessionId? / kind / exitCode? / durationMs? / stdout / stderr`；`opts` 含 `maxBytes? / dir?`
  - `pruneDiagnostics(retentionDays, dir?, now?)`
  - `redactSensitive(text)`
- 路径：`$STATE_DIR/logs/diagnostics/YYYY-MM-DD/{ts}-{taskId}.log`；目录 `0700`，文件 `0600`。
- 文件内容：元信息头（taskId / sessionId / kind / exitCode / durationMs / 时间）+ stdout / stderr 分段。
- 总大小 ≤ `diagnosticMaxBytes`（默认 64KB）：先扣除头部，再按 stdout / stderr 动态分配；一方为空时另一方拿满；截断处写 `…[truncated N bytes]`。
- `redactSensitive` 覆盖：`Bearer ...`、`token/access_token/refresh_token/secret/cookie/password/authorization` 赋值、`sk-...`。
- `pruneDiagnostics` 按目录 mtime 删除超过保留天数的日期目录/文件，返回删除数量。
- 写入失败不抛异常，返回空路径；由调用方记 warn。
