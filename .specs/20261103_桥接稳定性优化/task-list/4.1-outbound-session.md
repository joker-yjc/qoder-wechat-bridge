# 4.1 OutboundSession 预算 / 额度 / 失败分类

- 所属任务组：T4. 服务编排与命令
- 硬前置：1.2、1.3、2.1

## 目标

把“预算 + 额度耗尽 + 失败分类 + 分片入队”收敛为一个可单测的组件，供 `service.ts` 统一调用。

## 实现要点

- 新增 `src/bridge/outbound.ts`，导出 `OutboundSession` 与 `OutboundSessionOptions`。
- 构造参数：`state`、`policy`、`maxChars`、`send(item)`、`now?`。
- 字段：`budget`、`quotaExhausted`、`sessionExpired`、`sentCount`。
- `sendSingle(text, { kind, queueOnFailure })`：
  - `budget <= 0` 或 `quotaExhausted` → 入队，返回 `queued`；
  - 调用 `send`，用 `classifySendError` 分类；
  - 成功：`budget -= 1`、`sentCount += 1`，返回 `sent`；
  - `quota`：`quotaExhausted = true`，入队；
  - `session_expired`：`sessionExpired = true`，入队；
  - `transient` / `permanent` / `unknown`：入队（永久 / 未知带 `failures=1`，瞬时带 `transientFailures=1`），返回 `queued`；
  - `queueOnFailure=false` 时只记录，不入队。
- `sendChunked(text, { kind, taskId })`：
  - 用现有 `chunkText(text, maxChars)` 分片；
  - 逐片发送；任一片失败（含预算 / 额度）→ 当前及后续全部按顺序入队并停止本轮；
  - 成功片 `budget -= 1`、`sentCount += 1`。
- `enqueue(text, { kind, taskId, failures?, transientFailures? })`：计算 `bytes`，调用 `pushOutbox`，返回 `dropped`。
- 所有发送日志由本组件或调用方统一记录 `category / chars / bytes / attempts`，不记录正文。
