# 1.3 发送错误类型化与 client 回执映射

- 所属任务组：T1. 测试与模型基础
- 硬前置：1.1

## 目标

把 `sendMessage` 的 HTTP 错误和业务回执统一成 `BridgeSendError`，让上层状态机可以按 `kind` 分支，而不是靠字符串匹配。

## 实现要点

- 新增 `src/weixin/errors.ts`：
  - `SendFailureKind = 'quota' | 'session_expired' | 'transient' | 'permanent' | 'unknown'`
  - `BridgeSendError` 携带 `kind / ret / errcode / httpStatus`
  - `classifySendError(err)`：识别 `BridgeSendError`、`TimeoutError` / `AbortError` / `TypeError`（fetch 网络错误）并归类
- `src/weixin/client.ts`：
  - `postJson` / `getJson` 在 HTTP 非 2xx 时抛内部 `HttpError(status, body)`
  - `sendItem` 把回执映射为 `BridgeSendError`
  - 映射规则：`ret=-2` → `quota`；`ret/errcode=-14`、401/403 → `session_expired`；429 → `quota`；408/5xx → `transient`；400/413/422 → `permanent`；其它非零 → `unknown`
  - 保留 `SESSION_EXPIRED_ERRCODE` / `CONTEXT_INVALID_RET` 导出
- `src/index.ts` 导出 `BridgeSendError`、`SendFailureKind`、`classifySendError`。
