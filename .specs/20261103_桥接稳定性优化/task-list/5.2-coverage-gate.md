# 5.2 覆盖率门禁、全量回归与构建校验

- 所属任务组：T5. 集成与门禁
- 硬前置：5.1

## 目标

开启 95% Lines 覆盖率门禁，跑全量测试、类型检查和构建，补齐缺口；不引入新功能。

## 实现要点

- `vitest.config.ts` 开启 `coverage.thresholds.lines = 95`。
- 覆盖率范围为本 feature 触达的核心模块（配置、状态机、错误分类、诊断、qoder 调用、预检、stop、outbox/outbound、service、status、notify、client）；`src/cli.ts` 为 CLI 胶水层，由手工/集成验证，`src/index.ts` 仅导出，二者不纳入单测行覆盖门禁。
- 运行全量覆盖率，定位低于 95% 的文件，按 `unit-test` skill 补齐用例；优先补行为分支，不为凑覆盖率写低价值断言。
- 若发现实现缺陷，只做最小修复并补回归用例；不扩大功能范围。
- 运行类型检查、构建与发布自检，确认 `dist` 产物正常。

## 引用

- 需求：N5、成功标准 5
- 设计：`design.md` 8.1–8.6

## 验证命令

```bash
npm run typecheck
npm run test:coverage
npm run build
node scripts/check-publish.mjs
```

## 验收标准

- `src/**/*.ts` Lines 覆盖率 ≥ 95%。
- `npm run typecheck`、`npm test`、`npm run build`、`node scripts/check-publish.mjs` 全部通过。
- 无未覆盖的关键失败分支（额度、隔离、错误限长、stop、预检）。
