# 1.2 新增队列配置与状态 v2 模型

- 所属任务组：T1. 测试与模型基础
- 硬前置：1.1

## 目标

把设计 5.1.10 / 5.2 的配置字段、outbox / 隔离区实体和状态 v2 落到 `config.ts`，并提供旧状态迁移与归一化。

## 实现要点

- `Config` 新增字段并接入 `ENV_OVERRIDES`：
  - `outboxMaxItems`（200，`QWB_OUTBOX_MAX`）
  - `outboxTtlMs`（86_400_000，`QWB_OUTBOX_TTL_MS`）
  - `poisonMaxAttempts`（3，`QWB_POISON_ATTEMPTS`）
  - `transientMaxAttempts`（10，`QWB_TRANSIENT_ATTEMPTS`）
  - `quarantineMaxItems`（500，`QWB_QUARANTINE_MAX`）
  - `quarantineTtlMs`（604_800_000，`QWB_QUARANTINE_TTL_MS`）
  - `userErrorMaxChars`（300，`QWB_USER_ERROR_CHARS`）
  - `diagnosticMaxBytes`（65_536，`QWB_DIAG_MAX_BYTES`）
  - `diagnosticRetentionDays`（7，`QWB_DIAG_RETENTION_DAYS`）
  - `preflightVersionTimeoutMs`（5_000，`QWB_PREFLIGHT_VERSION_TIMEOUT_MS`）
- `OutboxItem` 扩展：`kind: 'reply' | 'notice' | 'error'`、`bytes`、`failures`、`transientFailures`、`lastErrorKind?`、`lastErrorAt?`、`taskId?`；旧 `attempts` 不再作为主字段。
- 新增 `QuarantineItem`：`OutboxItem` + `quarantinedAt`、`reason`、`preview`。
- `State` 新增：`version: 2`、`quarantine: QuarantineItem[]`、`quota: { streak: number; lastAt: number }`。
- 新增 `normalizeState(raw)`：兼容旧状态 `attempts → failures`，补齐 `bytes` / `kind` / `transientFailures` / `taskId` / `quarantine` / `quota` / `version`。
- `loadState()` 改为读取后经过 `normalizeState`；`DEFAULT_STATE` 同步为 v2。
- `src/index.ts` 导出新增类型。
